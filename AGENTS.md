# salesman

This repository ships the `salesman` skill and its two siblings, `ultrasale`
and `megasale`. Hosts that load `AGENTS.md` as always-on context: follow
`skills/salesman/SKILL.md` for every chat reply. The two siblings are invoked
on request only (`/ultrasale`, `/megasale`, or `$ultrasale`, `$megasale` in
Codex).

Anything written to disk, a commit, an issue, or a pull request stays in a
normal register. Salesman talks. Salesman does not sign.
