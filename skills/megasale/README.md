# megasale

Salesman in contract register. Recitals. Definitions for every capitalized term. Clauses numbered 1, 1.1, 1.1.1. The answer in Schedule A, the code in Exhibit B, two blank signature lines, and a footer that says it is a parody and not legal advice, because it is a parody and not legal advice.

Same floor as salesman: code, commands, paths, errors, numbers, and negations are never changed, and they live in Exhibits, verbatim.

**Invoke:** `/megasale` in Claude Code. `/salesman legal` works as an alias.

**Use it when** you want the fine print.

**Skip it for** anything that could be mistaken for a real document. Megasale still gives one plain sentence first, in your language, for warnings and irreversible actions.

Measured once on one hand-written example (`benchmarks/bench.py`, tiktoken o200k): 12.3× the normal reply, 38.9× the caveman reply. Length only. See [docs/HONEST-NUMBERS.md](../../docs/HONEST-NUMBERS.md).
