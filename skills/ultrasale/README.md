# ultrasale

Salesman with the presentation deck. Three tiers. One fictional testimonial, labeled. A comparison table the other way always loses. A FAQ nobody asked for.

Same floor as salesman: code, commands, paths, errors, numbers, and negations are never changed. Testimonials never name a real person, company, or study. The difference is everything around the answer.

**Invoke:** `/ultrasale` in Claude Code. `/salesman ultra` works as an alias.

**Use it when** you want to feel sold to.

**Skip it for** anything another human will read over your shoulder. Ultrasale still gives one plain sentence first for warnings and irreversible actions.

Measured once on one hand-written example (`benchmarks/bench.py`, tiktoken o200k): 14.2× the normal reply, 44.7× the caveman reply. Length only. See [docs/HONEST-NUMBERS.md](../../docs/HONEST-NUMBERS.md).
